Arsitektur Hardware

Spesifikasi Komponen Riset

Komponen kelas industri yang dipilih untuk ketahanan lapangan dan akurasi pengukuran tinggi.

🧠

Mikrokontroler Utama

ESP32-WROOM-32U / STM32
  • Dual-core 32-bit LX6 Microprocessor
  • Wi-Fi 802.11 b/g/n & Bluetooth v4.2 BR/EDR
  • Ultra-Low Power Consumption Sleep Mode
  • Konektor Antena Eksternal IPEX
Peran: Otak pemroses data & transmisi telemetry
🎚️

Modul Sensor Air

Industrial Grade Probe Set
  • Sensor pH BNC Electrode Kit (0 - 14 pH)
  • Optical Turbidity Sensor (0 - 1000 NTU)
  • Waterproof DS18B20 Temperature Probe
  • Analog TDS Meter (0 - 1000 ppm)
Peran: Pengambil sampel data fisik air
☁️

Protokol & Server

MQTT / HTTP REST API
  • Broker MQTT dengan enkripsi TLS/SSL
  • TimescaleDB / InfluxDB Time-series Database
  • Bot Notifikasi Alert Telegram
  • Web Dashboard HTML5 + Chart.js
Peran: Manajemen data, visualisasi & alert
